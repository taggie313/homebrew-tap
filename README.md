# taggie313/homebrew-tap

Homebrew formulae for [Elusive](https://elusive.net) tools.

```sh
brew tap taggie313/tap
brew install fontfetch
```

## fontfetch

Supplies missing fonts to any macOS app, on demand, instead of letting it
complain. Source: <https://github.com/taggie313/fontfetch>

```sh
brew install fontfetch
brew services start fontfetch
```
